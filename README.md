# Gokul Calculator

A clean, responsive calculator website built with HTML, CSS, and JavaScript.

## Live Demo

[Open Gokul Calculator](https://calculator-gokul-2cc8.vercel.app)

## Features

- Addition, subtraction, multiplication, and division
- Percentage and decimal calculations
- Clear and delete buttons
- Keyboard support
- Responsive design for desktop and mobile
- Handles division by zero safely

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Gokul-s-008/calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

No extra installation is required.

## Deployment

This project is deployed using [Vercel](https://vercel.com/). Changes pushed to the `main` branch can be deployed automatically.
